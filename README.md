# NEXUS DUEL AR — Monster Atlas Edition

Canlı kaynak: `index.html`

## İçerik
- 24 ikonik canavar
- ATK / DEF
- Attribute
- Level / Rank / Link
- Kullanıcı / Duelist
- Ana özellik
- Oyun tarzı
- Destekler
- Fusion materyali
- Tema / rol
- 8 ana canavar türü
- Arama ve tür filtresi
- Yüklenen canavar atlası görseli (sayfa içine gömülü)
- Three.js 3B çağırma
- WebXR immersive-ar
- Hit-test ile gerçek yüzeye yerleştirme
- Arka kamera fallback
- Mobil uyumlu UI

## Çalıştırma
HTTPS üzerinden aç. WebXR desteklenmeyen cihazlarda 3B ve kamera fallback modu çalışır.
